An offline trophy guide and progress tracker for the 55 PS5 trophies of Grand Theft Auto VI. Every trophy carries a full guide — how to earn it, steps for the grinds, and missable warnings — plus a five-stage "Road to the Platinum" roadmap, per-grade progress bars, filters and search, a spoiler shield for story trophies, and a checklist that persists in your browser. Everything runs client-side; no network, no libraries.

Built for the [gta6-trophy-guide-01 bounty on make.fun](https://make.fun/bounty/gta6-trophy-guide-01).

## Run it

```
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
